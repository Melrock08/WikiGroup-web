Descripción del proyecto

El proyecto WikiGroup es una plataforma web para centralizar la documentación técnica y administrativa de proyectos de software. Permite organizar arquitectura, requerimientos, diagramas, endpoints y pruebas en un único sitio.

Está desarrollado con Spring Boot, Thymeleaf y MySQL, siguiendo principios de arquitectura modular y escalabilidad.

Requerimientos funcionales

  • Registrar y mostrar información de los miembros del equipo.
  • Documentar arquitectura del sistema con diagramas actualizados.
  • Registrar casos de prueba para frontend y backend.
  • Formulario de contacto con validaciones estrictas.
  • Visualizar versiones y cambios de despliegue.

Requerimientos no funcionales

  • Compatibilidad con Chrome, Firefox, Safari y Edge.
  • Interfaz moderna, responsiva y accesible.
  • Tiempo de carga inicial menor a 3 segundos.
  • Base de datos en máquina virtual segura.
  • Disponibilidad mínima del 99%.

Descripción de endpoints

  • GET /equipo - Lista los miembros del equipo.
  • GET /proyecto - Muestra la documentación del proyecto.
  • POST /contacto - Guarda un mensaje del formulario.

Casos de prueba frontend

Pruebas de usabilidad, validación de formularios y visualización en diferentes dispositivos y navegadores.

Casos de prueba backend

Pruebas unitarias con JUnit y Mockito, además de pruebas de integración API-Base de datos.
