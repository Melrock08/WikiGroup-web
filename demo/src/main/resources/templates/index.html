Bienvenido a WikiGroup

Somos un equipo de desarrollo apasionado por crear soluciones tecnológicas innovadoras. Esta wiki documenta nuestro proyecto, los avances, las tecnologías usadas y las personas que lo hacen posible.

Objetivos del Proyecto

  • Desarrollar una aplicación web moderna y funcional para la gestión de información.
  • Implementar una arquitectura sólida y escalable usando Java, Spring Boot y Thymeleaf.
  • Garantizar calidad de software mediante pruebas unitarias y de integración.

Tecnologías Utilizadas

Backend

Spring Boot, Java 21, Hibernate, MySQL

Frontend

HTML5, CSS3, JavaScript, Thymeleaf

Herramientas

GitHub, Maven, VS Code

Resumen del Proyecto

El objetivo de WikiGroup es centralizar toda la documentación técnica y funcional del desarrollo de nuestro software. Aquí encontrarás información del equipo, arquitectura del sistema, endpoints, casos de prueba y mucho más.
