# WikiGroup-web
Una Wiki interactiva que permite al usuario entrar y consultar los temas de su mayor interes, siendo la mejor Wiki hasta el momento conocida. 

Esta aplicación es una plataforma wiki 🌎 que permite a los usuarios explorar, buscar y agregar información sobre diferentes temas ⚡. 
Utiliza una base de datos para almacenar la información 💻 y JavaScript para las funcionalidades interactivas 🕹️, ofreciendo una 
experiencia de usuario dinámica y fácil de usar 👥.

## Funcionalidades principales
🔍 Búsqueda por temas y filtrado dinámico.
📂 Almacenamiento en base de datos MySQL.
🖋 Edición y creación de artículos desde la interfaz.
📊 Listado y categorización de contenido.
